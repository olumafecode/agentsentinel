# Dashboard

The web screens that security analysts, approvers and administrators use: recent decisions, risk scores, pending approvals, incidents, agent status and service health.

| | |
|---|---|
| First built in | Sprint 3 |
| Stories | US-22, US-03 (approval screen), US-06b (incident timeline), US-09 (health tiles), US-08 (admin form, Should) |
| Requirements | FR-15, FR-20; NFR-12 |

## What belongs here

- Dashboard application code and its tests
- Playwright end-to-end tests for the screens

## Rules for this folder

- Show every decision with a plain-English reason.
- Every control must be reachable by keyboard and text must meet WCAG AA contrast (NFR-12).
